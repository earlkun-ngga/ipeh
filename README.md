# IPEH (Inspektorat PHP)
Aplikasi yang berguna untuk mengecek versi PHP dan apakah versi yang lu Pake, kena CVE-2026-109618 &amp; CVE-2026-109619

ini cocok untuk cek versi php apa aja yang di pakai domain2 atau user2 yang ada di server lu. ringan, karena based on bash script.

Req:
  - OS Linux Server
  - Bash installed

Menu 1-2 itu cocok untuk AlmaLinux dan terpasang Cpanel/WHM.

Cara pakai:
- bash -n ipeh.sh (pas pertama kali clone / download aja)
- bash ipeh.sh
